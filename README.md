## איך מוסיפים בן משפחה

פתח את הקובץ `index.html` ב-GitHub וחפש את שם ההורה.  
כל בן משפחה נרשם בפורמט הבא:

```
{nm:'שם מלא', dt:'שנת לידה'}
```

אם יש לו ילדים, מוסיפים `ch:[...]`:

```
{nm:'שם מלא', dt:'שנת לידה', ch:[
  {nm:'שם ילד', dt:'שנת לידה'},
  {nm:'שם ילד נוסף', dt:'שנת לידה'},
]}
```

נישואין מסומנים עם ⚭ בשם:
```
{nm:'ישראל ⚭ שרה', dt:'ישראל: 1950 • שרה: 1953'}
```
